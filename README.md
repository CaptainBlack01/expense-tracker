# TrackPulse - Expense Analytics Dashboard

TrackPulse is a single-page expense tracker and financial analytics dashboard built with vanilla HTML, CSS, and JavaScript.

## Features
- **Real-Time KPIs**: Track Net Balance, Total Income, Total Expenses, and Savings Rate.
- **Monthly Budget Monitor**: Visual progress tracking against your monthly spending target with threshold indicators.
- **Interactive Canvas Charts**:
  - Cash Flow Dynamics (Income vs. Expense over time)
  - Category Expense Breakdown Donut Chart
- **Financial Insights**: Quick-view cards for top spending area, daily average spending, and largest expense.
- **Transaction Management**: Filter by timeframe, category, and type; full search and sorting.
- **Local Persistence**: Uses `localStorage` with zero backend dependencies.
- **Data Portability**: One-click CSV export.

## Tech Stack
- Vanilla HTML5
- Vanilla CSS3 (Strictly Zero CSS Variables)
- Vanilla JavaScript (ES6+, Canvas API, WebStorage)

## Getting Started
Clone or download this repository and open `index.html` in any modern web browser.
